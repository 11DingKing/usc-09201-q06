# 石斛种源追溯网领域约定

项目面向集体林权改革与林下产业协作场景，业务记录需要区分来源、发生时间与当前有效版本。涉及个人、机构或敏感地点的信息只应向职责范围内的角色开放，所有对外结果都应能够追溯到采用的数据版本。

## 核心原则

1. **事件不可变（append-only）**：母本登记、育苗批登记、检验、转运、定植、拆分、合并、召回都是只追加的事实。已写入的事件不可修改、不可删除。
2. **更正也是事实**：检测结果更正通过追加 `inspection_corrected` 事件表达；原始记录与历次更正均保留，当前有效结论取最后一次更正。
3. **发生时间与接收时间分离**：`at` 为业务发生时间（离线设备可补传过去时间），`recordedAt` 为服务器接收时间。投影按发生时间回放。事件发生时间不得早于主体登记时间。
4. **标签全局唯一**：母本编号、批次标签一经占用不得重复，防止来源不明种苗以重标签方式混入。
5. **数量账实相符**：剩余可用 = 初始数量 − 拆出 − 合并转出 − 定植；拆分、定植、合批均不得超过剩余可用数量。

## 事件链

| 事件 | 说明 |
| --- | --- |
| `mother_registered` | 母本登记（研究谱系源头） |
| `batch_registered` | 育苗批登记，`origin` 为 null（独立批）/ split / merge |
| `batch_split` | 拆批：父批划出数量，子批独立流转 |
| `batch_merged_away` | 合批：来源批次划出数量到目标批（仅同母本可合） |
| `inspection_recorded` / `inspection_corrected` | 检验记录与结果更正（对象可为母本或批次） |
| `transported` | 跨基地调拨（含调出/调入基地、承运、运单号） |
| `planted` | 仿野生定植（林地、地块、数量、农户标识） |
| `recall_issued` | 定向召回，附签发时刻影响范围快照 |
| `batch_quarantined` / `batch_quarantine_lifted` | 召回冻结批次 / 关闭召回解除隔离 |
| `notification_recorded` | 召回通知送达记录，按 召回+接收人 幂等去重 |
| `recall_closed` | 召回关闭 |

## 离线采集

- 设备可自带 `eventId`（同事件 id 补传直接去重）与 `idempotencyKey`（命令级幂等）。
- `POST /api/offline/sync` 按顺序重放一批命令，整包重复提交不产生重复事实。
- 与当前所在地矛盾的跨基地调拨必须提供运单号，否则拒绝。

## 定向召回与通知去重

- 召回沿 拆批/合批 谱系边向下游冻结全部批次，无关母本/批次不受影响。
- 影响范围包含：批次集合、定植点（林地+地块）、在田数量、剩余可用数量、涉及农户。
- 通知对象 = 涉及农户 + 受影响林地协调员 + 仍持有库存的基地协调员。
- 通知按 `recallId + recipientKind + recipientId` 幂等；`sync-notifications` 只通知新增对象，重复同步零写入。
- 召回快照固定留档签发时影响范围；实时影响通过 live impact 重新计算。

## 分权（RBAC）

| 角色 | 权限 |
| --- | --- |
| `researcher` | 母本写入、追溯读取、研究数据读取 |
| `nursery_worker` | 批次写入（登记/拆分/合批/转运）、追溯读取 |
| `inspector` | 检验写入与更正、追溯读取 |
| `base_coordinator` | 定植写入、农户联系方式读取、追溯读取 |
| `recall_officer` | 召回签发/同步/关闭、联系方式读取、追溯读取 |
| `auditor` | 仅追溯链只读（研究备注、农户联系方式均脱敏） |

研究数据（母本备注等）与农户联系方式分别保存：追溯事件中只出现 `farmerId`，联系方式存于独立通讯录，无权角色只能看到是否可联系而看不到号码。

## 季末演练场景

一个 3000 株育苗批拆给三处林地（1000/1000/500，父批余 500），跨基地调拨后全部定植；季末补录该批不合格检测后签发召回：
影响范围 = 父批+3 子批、3 个种植点、在田 2500 株、剩余可用 500 株、3 名农户；通知 3 农户 + 3 林地协调员 + 1 育苗中心协调员，重复同步不产生新通知；无关批次不被隔离。见 `test/drill.test.mjs`。
